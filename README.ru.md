# candy from shipuchka

Небольшие самостоятельные инструменты, выпавшие из личной операционной системы,
которая работает поверх ИИ-агентов. Каждый решает задачу, с которой я реально
столкнулась, откалиброван на живом репозитории, а не на демо, и ставится
отдельно — забираешь один файл и уходишь.

Ни фреймворка, ни платформы, ни регистрации. Разворачивай, что нужно.

## Что в коробке

### 🍬 [agent-context-drift](agent-context-drift/)

**Инструкция для агента — это код. Её надо линтить как код.**

`CLAUDE.md`, `AGENTS.md`, `.cursorrules` объясняют ИИ-агенту, как устроен ваш
репозиторий. Потом вы переименовываете папку — и никто их не обновляет.
Устаревший README раздражает человека; устаревшая инструкция *меняет поведение
агента*: он идёт по мёртвому пути с полной уверенностью.

Проверяет каждый упомянутый путь по реальному дереву. Без LLM, без сети, без
токенов: ~3 секунды, JSON-отчёт и балл дрейфа. В CI — через `--fail-over 40`.

```bash
cd agent-context-drift && python3 agent_drift.py --explain
```

Python 3.9+, только стандартная библиотека, один файл. 18 тестов держат классы
ложных срабатываний, из-за которых наивная версия отчиталась о 159 битых путях,
где настоящих было 8.

### 🍬 [creative-wander](creative-wander/)

**Машина идей, которая бросает кости сама, потому что модель не умеет.**

Попросите LLM придумать десять идей для постов — получите десять вариаций того,
что вы и так думаете. Попросите выбрать случайный фрагмент из заметок — она
выберет *связанный*, потому что искать связное и есть её работа. Для рождения
идеи это ровно неподходящий инструмент.

Поэтому случайность приходит извне модели: `wander.py` вытягивает фрагменты
архива через ГПСЧ операционной системы, со смещением к тому, что не открывали
месяцами. Пять агентов сталкивают эти фрагменты, ничего не зная о критериях
качества; пять судей оценивают результат позже, каждый по единственному
критерию и не видя, откуда идея взялась.

```bash
cd creative-wander && python3 wander.py 6 40 --root ~/notes
```

Методика плюс единственный скрипт, который ей нужен. Работает и без агентов —
прочитайте фрагменты сами, это уже делает бóльшую часть работы.

## Откуда название

Шипучка — это про газировку и конфету, и это то, как меня зовут в интернете,
где я вслух строю AI-нативные системы. Репозиторий — коробка, инструменты —
то, что внутри.

## Как пользоваться

Каждый инструмент независим: свой README, свои тесты, общего рантайма нет.
Скопируйте файл к себе в проект или склонируйте папку — оба способа рабочие.

Issues и pull requests приветствуются, особенно сообщения о ложных
срабатываниях вместе с куском текста, который их вызвал. Именно такие отчёты
превратили первый инструмент отсюда из шума во что-то пригодное.
