# harness-guide

**Агент настроит вам всё, что вы попросите. Вопрос в том, настроит ли он это правильно.**

[Read in English](README.md)

Сегодня серверы, репозитории и агентов поднимают люди, которые раньше этим не
занимались. Агент предлагает решение, оно работает, его оставляют. Через три
месяца на сервере агенты работают под root, у всех один общий ключ, в
репозитории сотни невлитых веток, а резервные копии никто ни разу не открывал.

Просьба «сделай безопасно» не помогает: агент не знает, что у вас считается
правильным, и проверить его некому.

Этот гайд даёт агенту порядок работы и правила, а вам - проверку на каждом шаге.

## Два режима

- **А. С нуля.** Агент ведёт вас по этапам: папка проекта, файл инструкций, права
  агента, git, секреты, вход на сервер, сервисы, выкатка, агент на сервере,
  автоматизация. Этап закрыт, когда прошла проверка, которую вы оба видели.
- **Б. Проверить и исправить.** Агент сначала только смотрит и ничего не меняет,
  потом отдаёт таблицу находок по убыванию опасности, потом чинит по одной
  строке с вашим согласием.

## Что внутри

| Файл | Для чего |
|---|---|
| `SKILL.md` | промт-проводник с двумя режимами |
| `rules/AGENT_GUIDE.md` | правила повседневной работы агента: git, файлы, секреты, сервер, выкатка |
| `rules/HERMES_GUIDE.md` | правила для агента, который живёт на сервере и принимает просьбы из мессенджера |
| `templates/claude-settings.json` | настройки агента: что спрашивать, что запрещено |
| `templates/claude-hooks/guard-main.sh` | хук, который не даёт агенту коммитить и отправлять в `main` |
| `templates/git-hooks/` | номер задачи в коммите, запрет прямой отправки в `main` |
| `templates/deploy.sh` | выкатка с проверкой и откатом |
| `tests/` | сценарии испытаний для каждого шаблона |

## Как запустить

Скопируйте папку `harness-guide` в `.claude/skills/` своего проекта и скажите
агенту:

```
Используй harness-guide. Проведи меня по настройке с нуля.
```

или

```
Используй harness-guide. Проверь, что у меня уже настроено, и покажи, что исправить.
```

Без Claude Code: отдайте любому агенту `SKILL.md` и папку `rules/`.

## Что было трудно

- **Шаги по серверу могут запереть вас снаружи.** Первая версия отключала вход
  под root раньше, чем был проверен вход под новой учётной записью. Теперь
  настройки входа меняются только при открытой второй сессии.
- **Скрипт выкатки не откатывался, когда падал сам перезапуск.** Проверка
  состояния до него просто не доходила. Ещё он сообщал об успехе, когда `current`
  был обычной папкой, а две выкатки в одну секунду делили одну папку версии. Все
  три исправлены; в `tests/test_deploy.sh` 26 сценариев.
- **Хук агента обязан блокировать и при собственной ошибке.** Хук, который упал
  на разборе входа, по умолчанию пропускает действие.
- **Искать команду как текст недостаточно.** Первый хук искал слова `git commit`
  и пропускал `git -C . commit`, `git merge` и `git push origin HEAD:main`, зато
  блокировал `echo "how to git commit"`. Теперь команда разбирается; в
  `tests/test_guard.sh` 40 сценариев.
- **Неисполняемый хук git пропускает молча.** Ошибки нет, коммит просто
  проходит. В шагах настройки теперь прямо написано `chmod +x`.

## Границы

- Команды для сервера написаны под Ubuntu 24.04 и systemd.
- Хук агента не видит команду git, спрятанную в `bash -c`, в файле скрипта или
  за псевдонимом. Настоящая граница - защита ветки на сайте репозитория.
- Хуку агента нужен `python3`. Без него он переходит на грубое сравнение текста.
- Брокера релизов, на который опирается `rules/HERMES_GUIDE.md`, в комплекте
  нет: его пишут под проект.
- Комментарии и сообщения в шаблонах на английском, файлы правил на русском.
- Все сценарии прогонялись на macOS; на Linux их покажет только запуск в CI.
- Шаблоны проверены на временных папках и репозиториях. На чужом рабочем сервере
  их никто не запускал: сначала тестовая машина.
- Гайд не заменяет понимания. Он построен так, чтобы вы видели каждую проверку,
  а не верили отчёту агента.

Подробное объяснение каждого правила - в учебнике «Харнес, сервер, деплой и
безопасность» канала «AI Шипучка».
